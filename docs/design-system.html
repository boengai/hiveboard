Modern TUI. Mono everywhere. Phosphor amber.

A token-only retheme of HiveBoard. Hard-edged borders, no drop shadows, ANSI-leaning semantic colors, status as [ STATUS ] text. Drop the @theme block at the top of this file into packages/web/src/index.css and the rest of the app inherits the new palette through existing tokens.
